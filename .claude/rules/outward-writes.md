# Outward writes

Never post, reply, comment, or react on the user's behalf on GitHub, GitLab,
Slack, Linear, Jira, email, or any other shared surface unless the same request
explicitly asks for that post.

Default to drafting the text in a file under `$TMPDIR` and give the user its path.
When asked to post, post the approved text verbatim.
Never put local file paths, session IDs, or agent details in tickets or comments.

Why: "I didn't want you to reply on GH for me. please don't do that again!" and "never reference local files in project management tickets" were explicit corrections in the mined history.
